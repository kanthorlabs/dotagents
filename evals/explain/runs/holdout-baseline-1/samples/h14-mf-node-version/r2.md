CI runs Node.js 22.11.0. The `test` job in `.github/workflows/ci.yml` reads the version from `.nvmrc`.

**Timeline**

1. A pull request or a push to `main` triggers the `ci` workflow.
2. The `test` job starts on `ubuntu-24.04`.
3. `actions/setup-node@v4` reads `.nvmrc` through `node-version-file` (`.github/workflows/ci.yml:13`). The file holds `22.11.0`.
4. The job installs Node 22.11.0, runs `npm ci`, then runs `npm test`.

`package.json` declares `engines.node` as `>=20`. That is a minimum for users. CI does not use it, so CI never tests Node 20.
