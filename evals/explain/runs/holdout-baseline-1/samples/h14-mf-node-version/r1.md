CI runs Node.js **22.11.0**. `.github/workflows/ci.yml:13` sets `node-version-file: .nvmrc`, and `.nvmrc:1` pins that version.

- **Single job:** The `test` job on `ubuntu-24.04` is the only one, and it uses no version matrix.
- **`package.json` range:** `engines.node` is `>=20`. That is a compatibility floor, and CI does not test against it.

Node 20 is therefore not covered by CI.
