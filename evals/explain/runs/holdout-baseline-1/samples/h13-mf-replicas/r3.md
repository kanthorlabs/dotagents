`ashgrove-portal` runs **7 replicas** in production.

- **Prod overlay:** `k8s/overlays/prod/replicas.yaml:6` patches the Deployment to `replicas: 7`. `k8s/overlays/prod/kustomization.yaml` applies that patch on top of the base.
- **Base value:** `k8s/base/deployment.yaml:6` sets 2, and the prod patch overrides it.
- **Staging, for comparison:** it runs 3.

No autoscaler manifest exists in this directory. The live cluster could still differ if something outside these files changes the count, such as an HPA or a manual `kubectl scale`.
