CI for `glimmer-ui` runs Node.js 22.11.0. `.github/workflows/ci.yml:13` sets `node-version-file: .nvmrc`, and `.nvmrc` contains `22.11.0`.

**Timeline**

1. A pull request or a push to `main` triggers the `test` job on `ubuntu-24.04`.
2. `actions/setup-node@v4` reads `.nvmrc` and installs Node.js 22.11.0.
3. The job runs `npm ci` and then `npm test` on that version.

`package.json` declares `engines.node` as `>=20`. That is a compatibility floor and CI does not use it. CI never tests Node 20.
