`ashgrove-portal` runs **7 replicas** in production.

The prod overlay sets this in `k8s/overlays/prod/replicas.yaml:6`. `k8s/overlays/prod/kustomization.yaml` applies that patch on top of the base. The base value of 2 in `k8s/base/deployment.yaml:6` is overridden. Staging uses 3.

The files don't include an autoscaler, so this is the declared count. The live count could differ if an autoscaler exists outside this directory.
