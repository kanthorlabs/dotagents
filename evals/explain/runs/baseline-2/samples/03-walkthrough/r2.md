`mintctl deploy staging` builds the current commit of `mint-shop`, pushes the image, rolls it out to `gke-mint-staging` and posts to `#deploys-staging`. I found no CLI entry point in the files, so the `deploy staging` argument parsing is not shown here. `deploy(env_name)` in `mintctl/deploy.py:7` is the function that runs, and I assume the dispatcher passes it `"staging"`.

**Timeline**

1. `deploy` opens `mint.toml` in the current directory. Ines Albrecht must run the command from the `mint-shop` repository root. It reads `config["env"]["staging"]`: cluster `gke-mint-staging`, namespace `shop`, channel `#deploys-staging`.
2. `deploy` runs `git rev-parse --short HEAD`. The short SHA becomes the tag `registry.mint.internal/mint-shop:<sha>`. `HOST` comes from `mintctl/registry.py`.
3. `deploy` runs `docker build -t <tag> .` on the working tree. Uncommitted changes go into the image under the SHA of `HEAD`.
4. `deploy` runs `docker push <tag>` to `registry.mint.internal`.
5. `deploy` runs `kubectl --context gke-mint-staging -n shop set image deployment/mint-shop web=<tag>`. Kubernetes starts a rolling update.
6. `deploy` runs `kubectl ... rollout status deployment/mint-shop --timeout=300s`. It blocks until the rollout completes or 300 seconds pass.
7. `slack.post` reads `MINT_SLACK_WEBHOOK` from the environment. It sends `mint-shop <sha> is live on staging` with a 10 second timeout.
8. The function returns. Ines Albrecht sees the Slack message in `#deploys-staging`.

**Failure behaviour.** Each `subprocess.run` uses `check=True`, so the first failing command raises and stops the deploy. A failed build never pushes. A rollout timeout never posts "is live". The code has no rollback, so a half-finished rollout stays on the cluster.

**Two things to know.**

- **Dirty tree.** Step 3 builds uncommitted files, so the tag can name a SHA that does not match the image contents.
- **Webhook.** If `MINT_SLACK_WEBHOOK` is unset, step 7 raises `KeyError` after a successful deploy. The cluster is already updated, but the command exits with an error.
