# SR-12: password change keeps other sessions alive

Reviewer: Ingrid Solberg, external security review, October 2026

## Finding

After a password change, every other device of the user stays logged in. A stolen phone keeps access for up to 30 days.

## Requirement

- After a password change, every other session of the user ends within 15 minutes.
- The device that changed the password stays logged in.
